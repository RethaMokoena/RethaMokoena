## 🚀 Featured Projects

### 💳 SafiPay

**Digital Wallet & Payments Platform**

`Java` `Spring Boot` `PostgreSQL` `Docker` `Microservices` `JWT` `REST APIs`

SafiPay is a fintech platform designed around digital wallets, payments, savings groups and merchant transactions.

**What I built**

• Designed a multi service Spring Boot backend with dedicated **gateway, user, wallet, payment, ledger, merchant, stokvel, fraud and webhook services**

• Implemented wallet creation, balance management, transaction processing and payment flows

• Built communication between services while maintaining clear service responsibilities

• Implemented authentication and authorization using **JWT and Spring Security**

• Used PostgreSQL and Spring Data JPA for persistence and transactional data management

• Containerised the platform using **Docker and Docker Compose**

• Developed an Angular frontend that communicates with the backend through the API gateway

• Worked through real distributed system challenges involving authentication, CORS, service communication, database consistency and container networking

---

### 🌐 FutureFeed

**Customisable Social Media Feed Platform**

`Java` `Spring Boot` `React` `PostgreSQL` `REST APIs`

FutureFeed is a social media application that allows users to control how content is prioritised in their feed.

**My role**

• Served as **Backend Team Lead** in a five person development team consisting of three frontend developers and two backend developers

• Designed and developed REST APIs using Spring Boot

• Implemented user registration, authentication, profiles, posts and follower relationships

• Developed configurable feed presets that allow users to assign different weightings to topics

• Designed backend logic responsible for selecting and prioritising posts based on user preferences

• Worked closely with the frontend team to define API contracts and integrate the React application with backend services

• Used layered architecture to separate controllers, services, repositories and persistence logic

---

### 🏙️ City Builder Simulation

**Software Modelling & Design Patterns**

`Java` `Object Oriented Design` `Design Patterns`

A software modelling project focused on applying established design patterns to a city simulation system.
